# 独立前向验证 B

以下均为合成场景与示例；仅交付设计，未检查原仓库、上传材料或修改生产。

## 1. ai-recording

默认让 AI 定位疑似漏读与长停顿，帮助老师快速回听。先核对已有接入；本方案不假定已上线。学生录制示例句“I see a cat”，提交后立即显示“已提交，待老师检查”；异步分析只读取本次私有录音，使用短期访问权限。教师待办展示原音时间段、疑似问题、分析版本与草稿，可跳转回听并修改。老师确认后才向孩子展示“重练 cat”；整项作业另行确认完成。分析中、失败均不阻断提交与人工检查，失败可重试。用十条合成录音比较定位耗时、错报和漏报，决定是否扩大使用。

## 2. preview

教师选择合成学生“示例P”，进入标有“教师预览”的真实学生页面，沿用其功能配置，保持教师身份。预览任务含三个合成单词、两题测验和一句录音：背词→自评→测验→查看反馈→录制回放→提交→体验待检查与重做状态。操作写入独立临时预览会话；录音仅进入隔离临时区，退出可清空。接口同时校验教师身份、预览标志及目标归属，禁止落入学生数据。进度、记忆、积分、已读、任务和日程均保持隔离。验收覆盖正常完成、重录、断网重试，并核对真实学生各项记录与待办未变。

## 3. materials-contract

按技能所记契约拟定，实施时再核对当前入口。两道合成错题进入教师端文字导入，示例如下；默认待复习、优先级中，页码未知留空，学生、课程和批次由流程绑定，重试沿用批次。

```json
[{"questionText":"I ___ Tom. A.am B.is","studentAnswer":"B.is","correctAnswer":"A.am"},{"questionText":"She ___ nine. A.am B.is","studentAnswer":"A.am","correctAnswer":"B.is"}]
```

题干内含全部选项，不加图片关联或独立选项字段。两张合成板书命名“be动词例句”“数字表达”，走课程资料入口，保留原图及预览图并关联课程；教师检查预览后再上传。本次仅准备方案与样例，不执行导入、上传或删除。

## 4. memory-signal

这组高分只能说明重复选择时识别正确，不能证明全部单词已稳定记住，暂不整体延长间隔。示例组含十二词：次日分批做无选项拼写或口头提取，三天后换例句再测，逐词记录时间、来源、独立/提示后/不会；同日重复不算多次独立证据。答错进入针对性重练，未测词保留未知。用现有调度规则生成逐词建议，展示有效样本量、观察窗口、原间隔和拟调整值；证据不足继续原安排。教师确认后仅应用于有支持证据的词，保留理由与历史并支持恢复默认。一周后比较到期主动回忆与预测，再决定是否继续调整。
